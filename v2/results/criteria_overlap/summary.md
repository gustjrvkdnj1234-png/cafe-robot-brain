# 전문가 선택 기준 비교 (v1 통계 재사용, 새 계산 없음)

- 입력: `results/step4/reap_600/stats_layer*.json` (v1, 카페 보정 600문항). 새 순전파는 하지 않았다.
- 네 기준 모두 v1의 50:50 가중 통계(고정 프롬프트 전체 가중치 = 문항별 토큰 전체 가중치)로 순위를 매겨, 기준만 다르게 했다. 동점은 라우터 확률 합, 그다음 번호 순(v1과 같음).
- REAP = 배정된 토큰에서의 g·‖f(x)‖ 평균, 빈도 = 배정 수, 기여 합 = 모든 토큰의 g·‖f(x)‖ 합, 기여 합 + 보호 = v1 규칙(층 토큰의 30% 이상을 받는 전문가는 항상 남김).
- 재배정 비율(v1과 같은 지표): 층의 top-8 배정 중 잘린 전문가로 가던 배정의 비율 = 가지치기 뒤 다른 전문가로 바뀌어야 하는 배정. 30개 층 평균. ‘4b 기준’은 고정 프롬프트를 한 번만 센 원래 통계, ‘50:50 기준’은 가중 통계.
- 층 번호는 0부터 센다(0~29).
