# STT 힌트·짧은 창 비교 (CPU, 오프라인, 녹음 20개)

기본 디코딩은 bench_stt.py와 같다(한국어 고정, beam 1, temperature 0, 타임스탬프 없음, 스레드 8, int8). 지연 = 메모리에 올린 16 kHz 녹음 한 개의 인식 시간, 중앙값. CER = 띄어쓰기·문장부호 빼고 글자 단위.

- 힌트(prompt) = `initial_prompt`, 힌트(hotwords) = `hotwords`. 힌트 문장은 menu.json의 메뉴 이름, 짧은 줄임말(3글자 이하이거나 온도를 뜻하는 것, 표기 변형 제외), 옵션 말에 말로 하는 옵션 말(반샷, 샷 추가, 큰 걸로, 테이크아웃, 포장, 매장, 캐리어, 덜 달게, 더 달게)을 더했다.
- 주의: 녹음 20개의 문장에 힌트 단어(캐리어, 아바라, 반샷 등)가 들어 있다. 힌트가 맞히는 단어를 고른 셈이라, 힌트로 줄어든 CER은 이 20개에서 유리하게 나온 값이다.
- short = 인코더에 30초 대신 녹음 길이 + 1초만 넣음(pad_or_trim 교체, 공식 옵션 아님). vad = `vad_filter=True`.
- 말 없음: 1.5초 무음 / 1.5초 약한 잡음을 넣었을 때 나온 글자(빈칸이 정상).
