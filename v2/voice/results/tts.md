# TTS 비교 (CPU, 오프라인)

응답 5문장, 예열 1문장 뒤 측정, 스레드 8. 지연 = 문장 전체 파형이 나올 때까지(스트리밍 없음). RTF = 지연 / 음성 길이. 되알아듣기 CER = faster-whisper medium이 합성음을 받아 적은 결과의 CER (낮을수록 발음이 또렷함, 음질 점수는 아님). 음성 파일은 `results/tts/<후보>/NN.wav`(커밋 안 함).

'표기 차이 제외'는 STT가 숫자로 적은 것(2잔·3잔)과 '께요' 표기를 오류로 세지 않은 값.
